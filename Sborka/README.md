# Сборка — лендинг

Посадочная страница для услуги «Сборка» (производство лендингов под рекламные кампании).

## Файлы

| Файл | Куда на Тильде |
|---|---|
| `sborka.html` | в блок Т123, **без** тегов `<html>`, `<head>`, `<body>` — только содержимое от `<header class="hdr">` до `</footer>` |
| `sborka-style.css` | в тег `<style></style>` |
| `script.js` | в тег `<script></script>` |

`sborka.html` открывается и локально: в нём есть `<head>` с подключением CSS и `<script>` в конце — это только для просмотра, на Тильду переносится содержимое.

## Что заполнить перед публикацией

Плейсхолдеры в вёрстке помечены классом `fill` — на странице они видны как серый текст с пунктиром.

1. **Цены** (экран «Форматы и цены»): `от [___] ₽` и `от [___] ₽ / мес`, плюс третий пункт в строке «Дополнительно».
2. **Работы** (экран «Работы») — главное. Шесть карточек, в каждой:
   - `src` картинки: сейчас стоят временные фото из сети. Заменить на скриншоты своих работ — загрузить в `/assets` на Тильде, опубликовать, вставить ссылку. Картинку сжать, до 1 МБ.
   - подпись строго в формате `[Название проекта] · [ниша] · собрано за [N] дня`. Срок обязателен: без него блок не работает.
   Если картинка не загрузилась, карточка показывает аккуратную заглушку, а не битую иконку.
3. **Платформа** в первом вопросе FAQ: `У нас сайт на [платформа]`.
4. **Контакты** в футере: `[телеграм / почта]`.

## Формы

Их две — на первом экране и в финале, как в ТЗ. Отправки на сервер нет: в `script.js` есть функция `sendLead(data)`, в неё нужно подставить свой обработчик (форма Тильды, вебхук, CRM). Сейчас она пишет заявку в консоль. Проверка полей и экран «спасибо» уже работают.

В данные заявки автоматически кладётся поле `variant` — какой вариант первого экрана видел человек.

## A/B первого экрана

В ТЗ три варианта оффера. Свёрстан вариант A, два других включаются параметром в адресе:

- `/` или `/?v=a` — от скорости (основной)
- `/?v=b` — от конкурентов
- `/?v=c` — от боли

Тексты лежат в `script.js`, объект `HERO`. Кегль заголовка для B и C задан отдельно в CSS (`[data-variant='b']`), потому что они длиннее.

Лить рекламу можно сразу на разные адреса и сравнивать конверсию по полю `variant` в заявках.

## Технические заметки

- Светлая тема, тёплая бумага + акцентный вермильон. Шрифты — Inter / Inter Tight / JetBrains Mono, подключаются через `@import` в первой строке CSS. Если шрифты не загрузятся, вёрстка переедет на системный набор без поломок.
- Mobile-first: одна колонка на телефоне, две на планшете, полная сетка от 1000px. Таблица цен на телефоне превращается в карточки, работы — в карусель со свайпом.
- Учитывается системная настройка «уменьшить движение»: анимации отключаются, контент виден сразу.
- Без JS страница тоже читается полностью (`<noscript>` в `<head>`).
